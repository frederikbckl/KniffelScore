# KniffelScore 🎲

A SwiftUI score sheet for Kniffel that handles turn order, subtotals, the bonus and the final ranking.
More intuitive UI and bigger buttons compared to currently available Apps.

## Usage

Open `KniffelScore.xcodeproj` in Xcode and run on the simulator or on your iPhone via cable.
